# Fernanda Ferreira - Product Designer

Portfólio pessoal desenvolvido para apresentar projetos de Product Design, UX/UI, Branding, Identidade Visual e experiências digitais.

O projeto foi pensado como uma experiência visual contínua, minimalista e experimental, combinando tipografia expressiva, animações, imagens e elementos 3D.

## ✦ Preview

Portfólio: em breve

## ✦ Sobre o projeto

Este portfólio foi desenvolvido com foco em:

- Experiência visual e interação
- Design responsivo
- Navegação fluida
- Apresentação de projetos
- Animações e microinterações
- Elementos 3D
- Modo claro e modo noturno

A página principal apresenta uma experiência contínua dividida em três momentos:

**Hero → Work → Talk**

Cada projeto possui uma página própria com sua apresentação e galeria de imagens.

## ✦ Tecnologias

- HTML5
- JavaScript
- Tailwind CSS
- Three.js
- Vite
- CSS3

## ✦ Funcionalidades

- Portfólio responsivo
- Navegação por âncoras
- Páginas individuais para cada projeto
- Galeria de imagens com transição automática
- Animações baseadas em scroll
- Elementos 3D utilizando Three.js
- Night Mode
- Persistência do tema utilizando `localStorage`
- Menu responsivo para dispositivos móveis
